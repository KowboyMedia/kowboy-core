# Inheritance check: the nine drawings of the new admin area

**Verdict:** Partly inherited. It is not seeded from the old admin's look (the frame and the look are Tabler's, and saving in windows is new), but the tenant page's layout and its way of changing one thing at a time come from the set-aside redesign of the old tenant page, and many texts, labels and sample names are the old admin's, several word for word. How sure: high on the texts, fairly high on the layout.

**New, with no match in the old admin:** no menu and only two kinds of page; a window for every change instead of one long form with one Save; the State column and the words Works, Problem, Not set up, Reads and Waiting; Rename, Change, Connect Vitec and the "Vitec is connected" window; the phone layout.

## To remove the inheritance

1. Lay the tenant page out from what an admin does there, without the From and To columns and the arrow, unless Patric keeps that layout as his own choice.
2. Decide how a thing is changed from the new area's needs, not the set-aside's "one line per thing with Edit"; write the footers fresh and order the site window by what a person does first.
3. Write the tenant's state line fresh instead of the old Overview's verdict, and place a button's sentence by the new design's own rule.
4. Write the Tenants line, the button labels and their sentences, the empty texts and the password hint fresh; keep an old label only as a named choice.
5. Pick the tenants list's columns from what an admin looks for; keep an old one only as a named choice.
6. Write Vitec's sentences fresh from what Vitec does, not by editing the old Vitec texts or the drafts.
7. Say where the values go as the plugin shows it: in WordPress under Kowboy Estates, then Settings.
8. Leave "Fetch everything again" out unless Patric asks for it.
9. Use sample offices, connections and tenants found nowhere in the old admin, its docs or staging.
10. Write the worker banner fresh from what the reader must do, not from the old check or the drafts.

**Seen on the way, not inheritance:** the sign-in placeholder you@kowboy.se shows which domain may sign in, where Patric wanted a neutral one (admin/src/pages/sign-in.tsx:58-60); Sign out has no sentence beside it (AGENTS.md definition of done 4); "Vitec refuses the office M41003 Nacka" puts the id before the name (definition of done 5); the Remove site window does not say that the site's history goes (Patric's rule 6, docs/admin-panel-rebuild.md:356); the drawings use the Inter font, not the system font DESIGN.md names.
