# InterestLevel

Nivå av intresse som en spekulant har på en bostad. Ju lägre värdet är desto mer intresserad är spekulanten.

| Name | Value | Description |
| --- | --- | --- |
| Reserved | 40 | Reserverat |
| Booked | 50 | Bokat |
| ParticipateInBidding | 60 | Deltar i budgivning |
| OnHoldInBidding | 70 | Stannat i budgivning |
| FollowingBidding | 75 | Följer budgivning |
| VeryInterested | 80 | Mycket intresserad |
| BeenAtOrComingToViewing | 90 | Varit/kommer på visning |
| Interested | 100 | Intresserad |
| Assigned | 110 | Anvisad |
| NotInterested | 200 | Ej intresserad |
| Archived | 300 | Arkiverad |
