R-007 Year built
When: the year built is shown
Then: display.year_built is year_built_text as the office wrote it ("c:a 1930"), or the
number year_built when there is no text, followed by year_built_description after a
comma when there is one. Nothing when both are missing.
CRMs: all
Examples: text "1936" → "1936"; number 1965, description "enligt taxering" → "1965, enligt taxering"
