R-012 Address line and location
When: an address is shown on a property, a project or an office
Then: display.address_line is street, then a comma, then postal code and city:
"Völundsgatan 3, 113 21 Stockholm"; missing parts are left out. display.location
(property, project) is the first of area name, city, municipality that is set.
CRMs: all
Examples: street "Storgatan 1", postal code "111 22", city "Stockholm" → "Storgatan 1, 111 22 Stockholm"
