# Rules ledger

One entry per rule, in plain language, no code (strategy §11). Each entry becomes one piece of
`engine/rules/` with its test, linked by the id. The engine reads universal names only
(docs/field-tables.md) and decides nothing from a value (AGENTS.md): every entry here formats
what the CRM sent, or lays it out; none classifies it.
